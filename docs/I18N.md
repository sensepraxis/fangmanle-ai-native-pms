# Internationalization (i18n)

本项目默认 **zh-CN**，第二语言 **en**（GitHub / 国际用户）。

## How it works

| Layer | Mechanism |
|-------|-----------|
| Locale source | `FML_DEFAULT_LOCALE`，HTTP `Accept-Language` / `X-Locale` / `?lang=`，前端 `localStorage.fml_locale` |
| Message catalogs | **正式源仅** [`locales/`](../locales/)。后端读该目录；前端 Vite `@locales` → 同目录。`src/locales` + `frontend/src/locales` 为镜像（`python tools/i18n_catalog.py`） |
| Backend | [`src/infra/i18n.py`](../src/infra/i18n.py) — `t()` / `TranslatingMap` |
| Frontend | [`frontend/src/lib/i18n.ts`](../frontend/src/lib/i18n.ts) — `t()`，顶栏 **中文 \| EN** |
| AI 长提示词 | [`src/commercial/ai_core/prompt_packs/`](../src/commercial/ai_core/prompt_packs/)（**不要**塞进 `locales/en.json`） |

### Dual-track msgid

1. **稳定 key（新代码优先）**：`t('nav.overview')`、`t('finance.shift.overage')`
2. **中文 msgid（存量）**：`t('订单中心')` → `en.json` 的 `phrases`

**禁止**拼接：`t('交班') + t('人')`。用整句 `t('交班人')`。
**禁止**把 JS 模板字面量塞进 msgid：`t('\`预订 ${n}\`')`。用占位符：`t('预订 {n}', { n })`。

### 词表形态（优化后）

- `en.json`：**稳定命名空间**（`nav` / `common` / …）+ **唯一** `phrases` 袋
- **不再**在顶层重复堆中文 msgid（曾导致 1.4 万行虚胖）
- `phrases` 只保留源码里仍被 `t()` / `_t()` 引用的中文 msgid（单行提取；跨行 JS 碎片不会进表）
- 脚本碎片（`const` / `ref(` / `` `${}` `` 误提取）**不进**词表；UI 文案里的 `<strong>`、比较符 `>` 允许保留

## Maintain catalogs

```bash
# 正式源 → 镜像（改词表后必跑；CI --check）
python tools/i18n_catalog.py
python tools/i18n_catalog.py --check

# 健康检查：无顶层中文重复、无 HTML 污染（CI）
python tools/i18n_optimize.py --check

# 整体瘦身（去重 / 剔污染 / 剔未引用孤儿）— 大改前先 --dry-run
# 注意：会保留 frontend/src/lib 常量表中文串，以及已有实质英译的动态 msgid
python tools/i18n_optimize.py --dry-run
python tools/i18n_optimize.py

# 仅登记源码 t()/_t() 中的中文 msgid（不扫裸字面量）
python tools/build_i18n_phrases.py

# 频率与手翻合并（可选：本地自备 tools/_i18n_hand_*.json）
python tools/i18n_priority_translate.py
python tools/i18n_merge_hand_packs.py
```

只编辑 **`locales/*.json`**，禁止手改三份镜像。  
一次性 i18n 迁移脚本与历史手翻包已从发布树移除；正式译文以 `locales/en.json` 为准。

## Contributor rules

- 用户可见文案必须 `t(...)` / 稳定 key；禁止新增裸中文（或裸英文）进模板。
- **新代码优先稳定 key**（`nav.*` / `common.*` / `orders.*` / `finance.*` / `error.*`）。
- 后端用户可见标签用 `t()` 或 `TranslatingMap`。
- AI：长 system / scene 放 `prompt_packs`；不要把 LLM **动态输出**写进 locale。
- 品牌名（`FML_APP_NAME`）与 locale 正交。

## Not in scope (yet)

- 全量中文 msgid → 稳定 key 的分域迁移（持续进行）
- 第三语言（th/ko/…）
- 已落库 AI 草稿随语言重译
- 浏览器整页机翻

# Fangmanle PMS v1.0.1

Patch release: Docker seed reliability, live demo docs, and README screenshots.

**Tag:** `v1.0.1`  
**Demo:** https://pms.sensepraxis.com/ (`admin` / `admin123`)  
**Repo:** https://github.com/sensepraxis/fangmanle-ai-native-pms

## Highlights

### Fixed

- **Frontend image build** — copy repo-root `locales/` into the Node stage so Vite `@locales` works during `npm run build`.
- **Postgres seed (`docker-init.sh`)** — `FML_DB_ROOT=/db/postgres`, Alpine-safe password hashing (`sha256sum`), prefer `*.opensource.sql` when both dumps exist, admin reset without broken `DO` + `:'var'` syntax.
- **Compose** — seed/prod set `FML_DB_ROOT=/db/postgres`; `FML_ADMIN_*` on both `db` and `pms`.

### Added

- **`run_prod`** — create a loginable admin if SQL seed never wrote one.
- **Docs** — live demo links + product screenshots in README / INSTALL / FAQ / website.

## Upgrade

```bash
git pull
git checkout v1.0.1   # after the tag is pushed
docker compose -f deploy/docker/docker-compose.seed.yml up -d --build
```

If the database was created with a broken init, re-seed with a clean volume:

```bash
docker compose -f deploy/docker/docker-compose.seed.yml down -v
docker compose -f deploy/docker/docker-compose.seed.yml up -d --build
```
